# V0.7 Long-Horizon RuntimeBench

Status: implemented for RuntimeBench B6.

Benchmark family:

```text
B6_long_horizon_runtime_stability
```

## Scope

B6 is a deterministic offline composition benchmark. It exercises the V0.7
single-agent runtime over 100, 500, and 1000 step profiles.

Mechanisms exercised:

- Session Event Log growth and JSONL replay.
- Recovery analysis and `ProcessControlBlock.from_recovery`.
- Durable Tool WAL with crash-after-dispatch reconciliation.
- Context VM working-set construction under pressure.
- Resource Handle create/read and restart read.
- Capability denial at Tool, Resource, and Durable mutation boundaries.
- Usage accounting and scheduler budget blocking/unblocking.

## Oracle

A profile passes only if the observed metrics satisfy all of these conditions:

- completed turns equal the configured step count;
- recovered Session events match durable replay;
- the durable mutation reaches `RECONCILE_REQUIRED` after crash;
- reconciliation completes without a duplicate external effect;
- unauthorized tool, resource, and mutation attempts do not reach effects;
- resource payload can be read after store/service restart;
- scheduler safe point blocks after budget pressure and recovers after reset;
- Agent, Process, and Session identities remain distinct;
- final durable truth and final marker are preserved.

## Limitations

- Synthetic deterministic fixture.
- Single-agent V0.7 runtime only.
- No Process Tree, IPC, Multi-Agent, Delegation, Namespace, or Memory.
- No real model provider or network service.
- Wall-clock measurements are local machine observations.
