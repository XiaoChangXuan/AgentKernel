# AgentKernel V0.7

## Release Positioning

AgentKernel V0.7 is the first evaluated single-agent Agent Runtime Kernel
baseline.

It is not a production-ready operating system, a complete multi-agent runtime,
a complete sandbox, or a model-intelligence benchmark.

## What V0.7 Adds

V0.7 adds a live Process Runtime layer:

- `ProcessControlBlock`.
- Process lifecycle validation.
- `ProcessManager`.
- `CooperativeScheduler`.
- READY / WAITING / BLOCKED / PAUSED / EXITED runtime states.
- Scheduler safe points.
- Pause and cancel requests.
- `UsageCollector`.
- `ProcessUsageSnapshot`.
- Runtime budget checks.

## Kernel Object Model

```text
Agent      = capability principal
Process    = runtime identity
Session    = durable journal / replay truth
Context    = model-visible projection
Resource   = durable externalized bytes/object
Scheduler  = runtime mechanism
Accounting = runtime observation
```

The V0.7 release keeps Agent, Process, Session, Context, Resource, Scheduler,
and Accounting as separate runtime concepts.

## Supported Claims

V0.7 supports these scoped claims:

- Session replay preserves durable facts for covered deterministic crash
  prefixes.
- WAL/reconciliation prevents duplicate execution in tested reconcilable fake
  service scenarios.
- ResourceHandle keeps large bytes outside model context while preserving exact
  durable access.
- Context VM reduces model-visible context in tested deterministic fixtures.
- Capability enforcement blocks tested unauthorized Tool, Resource, and Durable
  operations.
- Scheduler plus Accounting can block process execution at cooperative safe
  points when configured budgets are exceeded.
- V0.1-V0.7 runtime mechanisms preserve tested invariants in deterministic
  single-agent workloads up to 1000 logical steps.
- Kernel object boundaries remain separated in tested single-agent V0.7
  fixtures.

## Unsupported Claims

V0.7 does not support these claims:

- Universal exactly-once side effects.
- Production sandbox security.
- Multi-agent isolation.
- Delegation or revocation.
- Namespace isolation.
- Persistent memory.
- Preemptive scheduling.
- B8 scalability result.
- General production scalability.
- Semantic long-horizon reasoning.
- Superior model intelligence.
- AgentKernel beats Codex, OpenHands, Gemini CLI, LangChain, Letta, or any other
  project.

## How To Run

Run tests:

```bash
pytest -q
```

Run RuntimeBench:

```bash
python -m benchmarks.runtimebench
```

Run the process runtime example:

```bash
python examples/process_runtime.py
```

## Known Limitations

- Synthetic fixtures.
- Offline only.
- No network services.
- No real provider comparison.
- Local latency values.
- No repeated statistical performance evaluation.
- No production workload trace.
- No V0.8 Process Tree, IPC, Multi-Agent, Delegation, or Namespace.
- No V0.9 Persistent Memory.
