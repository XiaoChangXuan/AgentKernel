## 4. Process / Scheduler / Accounting Boundary

Current V0.7 boundary:

| Component | Boundary | Review result |
| --- | --- | --- |
| `ProcessControlBlock` | Kernel-owned runtime identity and lifecycle state. | Stable |
| `ProcessManager` | Kernel-owned live process table. | Stable |
| `CooperativeScheduler` | Kernel-owned scheduling mechanism over READY, WAITING, and BLOCKED state. | Stable |
| `UsageCollector` | Runtime observation of token, cost, tool, resource, and wall-time usage. | Stable |
| `ProcessUsageSnapshot` | Point-in-time runtime usage snapshot, not durable truth. | Stable |
| `DefaultAgentLoop` integration | Optional scheduler/accounting safe points around existing loop boundaries. | Stable |

Mechanism retained in Kernel:

- lifecycle transition validation;
- READY queue management;
- WAITING and BLOCKED registries;
- cooperative safe points;
- pause and cancellation request handling;
- budget comparison and runtime blocking.

Policy kept outside Kernel:

- model choice;
- budget increase/reset decisions;
- blocked-process resume or termination policy;
- retry and reconciliation policy after recovery;
- memory/context reclaim policy;
- capability grant assignment.

Review result:

```text
PASS
```

Scheduler and accounting remain runtime mechanisms. They do not take ownership
of capability authorization, resource storage, durable side-effect truth, or
Context VM policy.

| V0.6 Capability | Compatible | Agent remains the capability principal; Process stores only an immutable capability snapshot for attribution. |
| V0.7 Process Runtime | Stable | Process, Scheduler, and Accounting add live runtime control without replacing Agent or Session authority. |

Review result:

```text
PASS
```

No V0.1-V0.6 interface requires a major rewrite for the V0.7 alpha baseline.

## 6. Release Freeze Risks

| Risk | Severity | Release decision |
| --- | --- | --- |
| Process table is live runtime state, not durable state. | Medium | Accepted for V0.7; Session remains durable truth. |
| Runtime usage counters reset after crash. | Medium | Accepted for V0.7; accounting is observation, not ledger. |
| Shared ResourceService metrics attribution is not multi-process-safe. | Medium | Defer until multi-process/multi-agent design. |
| AgentState and ProcessState coexist. | Low | Accepted for compatibility; future cleanup can narrow double lifecycle surfaces. |
| Parent process field has no tree semantics. | Low | Accepted; Process Tree is explicitly out of scope. |
| Runtime Architecture Review was untracked at review start. | Low | Fixed by including it in the release freeze documentation commit. |
